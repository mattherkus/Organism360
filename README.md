# Атлас организма

Интерактивная схема тела: наведение и клик по органам, режим «Изучать», четыре викторины и 3D-просмотр органов.
На схеме 20 органов; органы малого таза зависят от схемы тела, которая выбирается в настройках:
на женской — матка и яичники, на мужской — предстательная железа.
В режиме «Изучать» панель «Слои» слева скрывает кожу, кости, вены, артерии, отдельные органы или все органы
сразу и показывает мышцы (по умолчанию они скрыты), а строка поиска над списком органов находит орган по названию на любом языке (или по системе органов):
единственный найденный подсвечивается на схеме, Enter открывает его карточку. В викторинах панели нет,
и органы видны все.
Там же, пока орган не выбран, карточка справа предлагает экскурсии — «Путь пищи», «Воздух и кровь»,
«Очищение и моча», «Управление: нервы и гормоны»: шаг за шагом подсвечивается орган
маршрута и рассказывается, что он делает; листать можно и стрелками, в конце — викторина по теме.
Окно можно растягивать: схема сразу масштабируется, а через мгновение перерисовывается чётко под новый размер.
Схема живая: сердце бьётся, лёгкие дышат (выключается в настройках, «Анимация схемы»).
Викторины: «Найди орган» (дано название, нужно нажать на орган), «Угадай название» (орган подсвечен,
нужно выбрать название из вариантов), «Угадай по факту» (дана функция, расположение или факт) и «Вперемешку»:
у каждого вопроса случайный тип — один из трёх прежних или пять новых: «Какой орган находится здесь?»
(дано расположение органа), «К какой системе органов относится…?», «Какой орган поражает болезнь?»,
«Что это за орган?» по латинскому названию и «Верно ли это про орган…?» (факт с карточки этого органа
или органа другой системы).
Перед игрой выбираются сложность (3, 4 или 6 вариантов; на сложном нет подсветки под курсором и факты
малоизвестные), таймер на вопрос, сколько вопросов (5, 10, 20 или все), тема (все органы или одна система
органов) и набор вопросов: все органы, ошибки прошлой игры или «пора повторить». Органы для игры каждый раз
выбираются случайно из всего набора и не повторяются, варианты ответа перемешиваются.
Результаты и карточки повторения (система Лейтнера: 1, 2, 4, 8, 16 дней) хранятся в progress.json рядом
с settings.json. По ним же считаются серия дней подряд с игрой и 12 достижений: кнопка «★» в верхней
панели, новые достижения показываются в итогах игры.
Схема тела рисуется программно (numpy + Pillow), интерфейс на Tkinter. В 3D-просмотре все органы показываются
анатомическими сетками из открытых атласов (см. «Анатомические модели»); процедурные модели остались запасными.
У модели из нескольких частей (камеры и сосуды сердца, отделы мозга, почки с мочеточниками...) под кадром
список частей: их можно скрывать, под курсором видно название части, а «Найди часть» — мини-викторина
прямо в 3D.

## Запуск

```bash
pip install -r requirements.txt     # numpy, pillow (tkinter входит в стандартный Python)
python run.py                       # или: python -m organism_atlas
```

Программа для Windows, которой не нужен Python (папка `dist/OrganismAtlas` с `OrganismAtlas.exe`):

```bash
pip install -r requirements-dev.txt
python tools/build_exe.py
```

Установщик (`dist/OrganismAtlas-Setup-<версия>.exe`: пользователь открывает его, выбирает папку и нажимает
«Установить»; нужен [Inno Setup 6](https://jrsoftware.org/isdl.php), либо его соберёт GitHub — см. «Установщик»):

```bash
python tools/build_setup.py
```

Подробнее — в разделах «Сборка .exe» и «Установщик».

Тесты (без окна, около полуминуты; большую часть времени занимают сравнения с эталонами в `test_golden.py`):

```bash
python -m unittest discover -s tests -t .
```

## Вопросы викторины

Вопросы режима «Угадай по факту» лежат в `organism_atlas/questions/`, по файлу на орган. Ответ на любой
вопрос из файла — этот орган, поэтому чтобы добавить вопрос, достаточно дописать его в нужный файл:

```json
{
  "questions": [
    {
      "level": "easy",
      "ru": "Мышечный насос, который гоняет кровь по сосудам.",
      "en": "A muscular pump that drives blood through the vessels."
    }
  ]
}
```

- `level`: `easy`, `medium` или `hard`. На лёгкой сложности спрашиваются вопросы `easy`, на средней `easy`
  и `medium`, на сложной `medium` и `hard` (`POOL` в `questions.py`).
- Текст на русском (`ru`) обязателен, переводы по желанию: без перевода вопрос покажется по-русски.
  Для нового языка достаточно дописать к вопросам ключ с его кодом (`"de": "..."`).
- Не называйте в вопросе сам орган (в том числе однокоренными словами: «…стенки желудка»): такой вопрос
  выдаёт ответ, и викторина его пропускает.
- Ключи, начинающиеся с `_` (например, `_comment`), игнорируются: туда можно писать заметки.

Вопрос может иметь свои варианты ответа — тогда отвечают не органом, а одним из вариантов:

```json
{"level": "medium", "ru": "Сколько камер у сердца?", "en": "How many chambers does the heart have?",
 "answer": "4", "wrong": ["2", "3", "6"]}
```

- `answer` — верный ответ, `wrong` — неверные; в игру берётся столько неверных, сколько нужно для
  выбранной сложности (3, 4 или 6 вариантов), а если их меньше — сколько есть.
- Строка и список подходят, когда варианты одинаковы на всех языках (числа). Если нет — словари по языкам:
  `"answer": {"ru": "Кровь", "en": "Blood"}, "wrong": {"ru": ["Лимфу", "Воду"], "en": ["Lymph", "Water"]}`;
  списки `wrong` на всех языках одной длины и в одном порядке, русский обязателен.
- Такой вопрос может называть орган: ответ на него — не орган. Ошибки и повторение по-прежнему считаются
  по органу, в файле которого лежит вопрос.

Проверить файлы после правки (сколько вопросов на каждом уровне и какие будут пропущены):

```bash
python -m organism_atlas.questions
```

Ошибка в файле (неверный JSON, неизвестный `level`, нет русского текста, файл с именем несуществующего
органа) показывается при запуске программы с названием файла и номером вопроса.
Вопросы не зависят от карточек органов в `lang/*.json`: факты на карточке и вопросы викторины правятся отдельно.

## Анатомические модели

Все органы показываются в 3D как анатомические сетки, построенные по срезам тела человека,
из трёх открытых источников:

| Источник | Органы | Лицензия |
|---|---|---|
| **BodyParts3D** (© The Database Center for Life Science) | сердце, мозг, печень, жёлчный пузырь, желудок, кишечник, почки, поджелудочная железа, мочевой пузырь, надпочечники, пищевод, прямая кишка, аппендикс, трахея | CC BY 4.0 |
| **Human Reference Atlas** (HuBMAP, по данным Visible Human) | лёгкие, селезёнка, предстательная железа, матка, яичники | CC BY 4.0 |
| **Атлас головы и шеи SPL** (Brigham and Women's Hospital, Open Anatomy) | щитовидная железа | 3D Slicer License, часть B |

Подпись источника выводится в панели 3D-просмотра под каждой моделью; подробности, ссылки на исходные
файлы и список изменений — `organism_atlas/models/mesh/ATTRIBUTION.md`.

- Для ориентира к некоторым органам добавлены соседние: к надпочечникам — почки, к пищеводу — желудок,
  к аппендиксу — слепая кишка, к щитовидной железе — перстневидный хрящ; матка и яичники показываются
  вместе с маточными трубами.
- Лёгкие раньше были реконструкцией из BodyParts3D (там нет поверхности лёгких, только бронхи и сосуды),
  теперь это измеренная поверхность из Human Reference Atlas.
- Цвет, текстуру и блеск частей можно менять в `models/mesh/<орган>.json`.
- Вернуть прежние модели: `"models": "procedural"` в `render3d/look.json`. Если файл сетки
  не читается, орган сам показывается процедурной моделью.
- Пересобрать сетки из оригинала: скачать `partof_element_parts.txt` и `partof_BP3D_4.0_obj_99.zip`
  со страницы https://dbarchive.biosciencedbc.jp/en/bodyparts3d/download.html и запустить
  `python tools/bp3d_import.py <папка с файлами>`; модели Human Reference Atlas и Open Anatomy —
  скачать файлы, перечисленные в `ATTRIBUTION.md`, в одну папку и запустить
  `python tools/atlas_import.py <папка с файлами>`. Параметр `--out <папка>` собирает модели в другую
  папку, например чтобы сравнить с текущими.

## Вид 3D-просмотра

3D-рендер программный (numpy): треугольные сетки, эллипсоиды и трубки в одном z-буфере.
Вид задаёт файл `render3d/look.json`:

- `style`: `realistic` (по умолчанию) или `classic` — прежний вид, совпадает с ним до пикселя;
- `lights`: ключевой, заполняющий и контровой свет (направления относительно камеры), цвет неба и пола
  для рассеянного света и отражений, `exposure` — общая яркость;
- `shadows`: мягкие тени от ключевого света (карта глубины); `ao`: затенение в щелях;
- `seams`: скругление освещения на стыках частей одной ткани (камеры сердца, доли печени);
- `materials`: по типу текстуры — шероховатость сухой и влажной поверхности, доля влажного блеска,
  просвечивание (`sss`), пятнистость цвета, сеть мелких сосудов.

Что делает реалистичный стиль: линейный цвет и tone mapping по яркости (блики не выгорают, оттенок
ткани сохраняется), аппроксимация подповерхностного рассеяния, влажный блеск с переменной
шероховатостью, отражение процедурной среды, мягкие тени, пятнистость и сосудистая сеть.
При вращении мышью рисуется облегчённый черновик (без теней и мелких деталей): его считают два
фоновых потока по очереди, а разрешение подстраивается так, чтобы кадры шли без задержек; окно
при этом не ждёт рендера. Полный кадр считается в фоне после отпускания. Если `look.json` не читается, 3D-просмотр включается
в классическом виде, а в консоль пишется причина.

Сравнение до/после для всех органов: `docs/3d_before_after.png`.

## Кэш схемы

Тело и органы рисуются с суперсэмплингом, на большом экране это несколько секунд. Результат
сохраняется в `%LOCALAPPDATA%\organism_atlas\cache\atlas-<версия>-z<масштаб>.npz` (около 2 МБ;
на других системах `~/.cache/organism_atlas/`, переменная `ORGANISM_ATLAS_CACHE` задаёт другую папку),
и следующие запуски читают его за доли секунды.

- Версия считается по исходникам рисунка (`atlas.py`, `geometry.py`, `colors.py`, `config.py`,
  `body/`, `organs/`, `render2d/`) и версиям numpy и Pillow. После правки рисунка схема
  перерисуется сама, а старые файлы удалятся; чистить кэш руками не нужно.
- Для другого масштаба (другой монитор, другой размер окна) появляется свой файл. Масштаб меняется
  ступеньками по 0,05, а хранится не больше `KEEP` (6) масштабов: давно не открывавшиеся удаляются.
- Папку кэша можно удалить в любой момент. Если она недоступна для записи или файл испорчен,
  схема просто рисуется заново.
- Если поменяете устройство самого файла кэша, поднимите `FORMAT` в `atlas_cache.py`.

## Тексты и языки

Все тексты лежат в папке `organism_atlas/lang/`, по файлу на язык. Их можно править в любом текстовом
редакторе (Блокнот, VS Code), программировать не нужно. Кнопки RU / EN / LA в правом верхнем углу
переключают язык на лету, не сбрасывая викторину. Выбор запоминается между запусками
(файл `%APPDATA%\organism_atlas\settings.json`; чтобы вернуть русский по умолчанию, удалите его).

- `ru.json` — основной язык, должен быть полным;
- `en.json` — английский перевод;
- `la.json` — только латинские названия органов. Остальное берётся из языка, выбранного перед латынью.

В каждом файле разделы `ui` (кнопки, подсказки, вопросы викторины), `organs` (карточки), `tours`
(экскурсии: `title`, `intro` и `steps` — рассказ про каждый орган маршрута; без рассказа показывается описание
органа) и `parts` (названия частей 3D-моделей по группам сетки из `models/mesh/<орган>.json`).
У органа: `name` (название), `desc` (описание), `location` (где находится), `facts` (факты),
`diseases` (частые заболевания) и `daily` (пул «фактов дня», каждый день показывается следующий).

Правила:
- текст пишется в кавычках, между элементами списка и полями ставится запятая, после последнего — нет;
- слова в фигурных скобках, например `{name}`, подставляет программа: их не переводить;
- если поле в файле пропущено, берётся текст из предыдущего выбранного языка, а затем из русского;
- **новый язык**: скопируйте `en.json` в, например, `de.json`, поменяйте `language` и `short`
  и переведите тексты. Кнопка появится сама.

Если в файле ошибка (забыта запятая или кавычка), при запуске появится окно с именем файла и номером
строки. Тесты (`python -m unittest discover -s tests -t .`) проверяют, что английский файл полный
и что `{…}` в переводах совпадают с русскими.

## Сборка .exe

`python tools/build_exe.py` (нужен PyInstaller из `requirements-dev.txt`) собирает папку `dist/OrganismAtlas`:
`OrganismAtlas.exe`, библиотеки в `_internal` и README. Её можно заархивировать и передать — Python на другом
компьютере не нужен. Настройки, прогресс и кэш схемы программа хранит там же, где и при запуске из исходников.

- В сборку входят все данные пакета: тексты, вопросы, 3D-модели вместе с подписями авторов и лицензиями
  (`models/mesh/ATTRIBUTION.md`, `LICENSE-3D-Slicer.txt` — их обязательно распространять с моделями).
- Исходники рисунка схемы тоже лежат в сборке как данные: по ним считается версия кэша схемы.
- **Первый запуск** только что собранной или распакованной программы может занять несколько минут:
  Защитник Windows проверяет новые библиотеки (numpy и Pillow). Следующие запуски — около секунды.
- `--onefile` собирает один `dist/OrganismAtlas.exe`: его удобнее передать, но при каждом запуске он
  распаковывается во временную папку и открывается полминуты-минуту, а папка — около секунды.
- `--console` — сборка с окном консоли: в нём видно ошибки, если программа не запускается.

## Установщик

`python tools/build_setup.py` собирает программу (`build_exe.py`) и по скрипту `tools/setup.iss` —
установщик `dist/OrganismAtlas-Setup-<версия>.exe`. Его достаточно передать пользователю: он открывает файл,
выбирает папку (или оставляет предложенную) и нажимает «Установить». Ярлыки в меню «Пуск» и на рабочем столе
создаются сами, в конце программу можно сразу запустить.

- Собирать самому не обязательно: GitHub собирает установщик при каждом push
  (`.github/workflows/setup.yml`, вкладка Actions → запуск → Artifacts). Тег `v<версия>`
  (`git tag v1.0.0 && git push origin v1.0.0`) выкладывает его в Releases — эту ссылку и стоит давать пользователям.
- Для сборки на своём компьютере нужен Inno Setup 6.3 или новее: `winget install JRSoftware.InnoSetup`
  или с https://jrsoftware.org/isdl.php. `ISCC.exe` ищется в PATH и в обычных папках установки;
  другой путь можно задать переменной `ISCC`.
- Версия берётся из `organism_atlas.__version__` — поднимите её перед выпуском новой версии:
  установщик новой версии ставит программу поверх старой, в ту же папку.
- Права администратора не нужны: по умолчанию программа ставится в `%LOCALAPPDATA%\Programs\OrganismAtlas`.
  Если выбрать папку, куда без них писать нельзя (Program Files), мастер сразу попросит выбрать другую.
  Для всех пользователей: `OrganismAtlas-Setup-<версия>.exe /ALLUSERS`.
- Язык мастера — по языку Windows (русский или английский), без лишних вопросов.
- Удаление — через «Приложения и возможности»: кэш схемы удаляется всегда, а про настройки и прогресс
  программа спрашивает.
- `--skip-exe` — собрать только установщик из уже собранной папки `dist/OrganismAtlas`.

## Эталоны тестов

`tests/test_golden.py` сравнивает схему и 3D-кадры с картинками из `tests/golden/`. Если рисунок органа
поменялся намеренно, посмотрите новые картинки и только потом перезапишите эталоны:

```bash
python tools/make_golden.py --out <временная папка>   # посмотреть, что получится
python tools/make_golden.py --force                  # перезаписать tests/golden
```
